## 📝 To‑Do List App (React + Vite)
A simple, clean, and modern To‑Do application built using **React** and **Vite**, converted from the original HTML/CSS/JS version. It supports adding, completing, deleting tasks, and includes **dark mode** and **localStorage persistence**.

---

## 🚀 Features
- ➕ Add new tasks
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- 🌙 Dark/Light theme toggle
- 💾 Saves tasks in **localStorage**
- ⏱ Shows timestamp for each task
- 📱 Responsive design

## 🛠️ Installation & Setup
Follow these commands to run the project locally:

### 1️⃣ Install dependencies
```
npm install
```

### 2️⃣ Start development server
```
npm run dev
```

The app will open at:
```
http://localhost:5173/
```

### 3️⃣ Build for production
```
npm run build
```

## 🧩 Technologies Used
- **React** (Functional Components, Hooks)
- **Vite** (Fast bundler + Dev server)
- **CSS3** (Custom styling, dark mode)
- **LocalStorage API**
